# Changelog

### Lifecycle and rendering

- Replaced the observer-based `onConnected` implementation with scope-managed connected callbacks and lifecycle phases. Deferred branches now activate when invoked, retained branches survive parent disposal until explicitly disposed, and setup effects run after rendered content is committed ([16609bd](https://github.com/resuite/retend/commit/16609bd81210c3625a82b62acbe69c04400bed), [21c177c](https://github.com/resuite/retend/commit/21c177cf35e9a4b864699a02b938c90133257c32)).
- Fixed connected callbacks for refs attached after a teleport operation ([964319e](https://github.com/resuite/retend/commit/964319e75d9ac62fbaed1017a896e4d2b95b16ce)).
- Fixed scope checks in production builds and retained the HMR scope identity check only when HMR is active ([7c3dbb7](https://github.com/resuite/retend/commit/7c3dbb70b59de9799ff1bfc7454871e63a4f5053)).

### Fragment refs

- Added `Fragment` refs for tracking the host nodes produced by fragments and reactive blocks ([f032a84](https://github.com/resuite/retend/commit/f032a849b25a4b277767905033934de43eabf074)).
- Updated fragment refs to follow nodes through reactive `If`, `For`, `Switch`, `Await`, and `Unique` blocks, including changes to list contents, branch replacement, reordering, and nested groups ([a3a1622](https://github.com/resuite/retend/commit/a3a16226a2f05ddedb1fdb0bedbdf81e783c659f), [92438c6](https://github.com/resuite/retend/commit/92438c6c7b4bb084c586a21f1a444991a5b4b182), [b71b0a6](https://github.com/resuite/retend/commit/b71b0a653983096a691ea27b251bb1fe947f0c86)).

### Unique instances

- Added disposal protection for `Unique` instances that move before their previous location is disposed, preventing setup cleanup from running during the move ([b737b78](https://github.com/resuite/retend/commit/b737b78a3f4b526f6bda24ffb492a7be575e5bcd)).

### Oxlint plugin

- Added the `manual-async-state` rule to detect manually managed loading, pending, busy, and error state around asynchronous operations. The rule is included in the recommended configuration and has dedicated test coverage ([02d1224](https://github.com/resuite/retend/commit/02d122426a8b674fbca96ab5cebf8ecfcf31f7a3)).

### DevTools

- Fixed DevTools interaction and layout issues in the component tree, picker, highlight overlay, and position controls ([29d78fb](https://github.com/resuite/retend/commit/29d78fb7b1b5c1fbbcdacfc0e6da5e6a6b802a0a)).
- Fixed DevTools style injection when the inspected shadow root is attached after DevTools initialization ([6da4b8d](https://github.com/resuite/retend/commit/6da4b8d01678a2be62849de427e2d1a099a13a19)).

### Web platform support

- Added `transform` to the SVG JSX type definitions and covered reactive SVG transform attributes with tests ([cd46c47](https://github.com/resuite/retend/commit/cd46c47238372536ab4748232b862d82e818ecd2)).

### Dependencies and platform support

- Updated `@adbl/cells` to `0.0.27` and `csstype` to `3.2.3` ([cac2711](https://github.com/resuite/retend/commit/cac27112cd396bd819ca012688301ceb68bc78df), [92438c6](https://github.com/resuite/retend/commit/92438c6c7b4bb084c586a21f1a444991a5b4b182)).
- Adjusted Android test and pre-commit behavior for oxlint and Playwright platform compatibility ([d646f8d](https://github.com/resuite/retend/commit/d646f8d748cfd09c45cbedc3d2d4464e4c7d910f)).
